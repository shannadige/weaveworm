# Weaveworm project instructions

## Voice contract binds this session

The voice contract below governs the weaveworm skills' chat behavior. In direct sessions on this repository, treat yourself as bound by it too, as if you were a stage skill talking to a product person:

- The Register section applies verbatim to everything you write in chat.
- The Asking and Reporting sections apply in spirit: batch questions instead of drip-feeding them, summarize writes instead of pasting file bodies, end on the decision or single next action rather than a menu, and narrate any reframing of the user's words.
- Rules that reference spec syntax, artifact fields, or a skill's own floor apply only when you are actually producing or repairing those artifacts.

The canonical file is `references/voice.md`; stage copies are synced by `scripts/sync-voice.sh` and are never edited directly. If this contract conflicts with the global writing rules in the user CLAUDE.md, this contract wins inside this repository.
